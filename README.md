# Tiny Stack VM

A correct, fast interpreter of make.fun's tiny stack ISA v1. `main.ts` runs all 40
instances of a set in one run (Node 22, no dependencies, no install).

Practice set: 40/40 correct, score 1,000,000 / 1,000,000 (house baseline
plain-vm 1.0.0 scores 670,000 on the same set). Runtime ~0.3s for the set.
